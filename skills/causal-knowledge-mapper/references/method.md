# Method and evidence rules

## Atomic claim test
A claim must name a subject, relationship, object, and scope when scope changes meaning. Prefer one relation per record. Preserve negation and hedging rather than rewriting a qualified statement as certainty.

## Evidence rules
- Every evidence record needs a source locator.
- `associated_with` is not causal proof.
- Record direct observations and mechanistic interpretations as separate claims/evidence records.
- Preserve contradictions. Explain contextual differences only where the source or clearly recorded analysis supports them.
- Use a shared `evidence_origin_id` for records based on the same experiment, dataset, or uninspected primary source.

## Question-focused answer format
1. Scoped answer in one paragraph.
2. Supporting evidence profile, grouped by claim.
3. Contradictions and boundary conditions.
4. What remains unestablished in the provided corpus.
5. Highest-value source check, measurement, or intervention.

## Quantitative effects
Add a quantitative effect only if the source gives an estimand, units, method, uncertainty where reported, and applicable conditions. Do not derive an A-to-C numerical effect from A-to-B and B-to-C claims without an explicit model.
